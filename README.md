# # CleanTodo

A clean, modern and focused todo application built with **vanilla JavaScript**.

## Features

- Add, complete and delete tasks
- Filter by All / Active / Completed
- Persistent storage (localStorage)
- Dark, minimal UI
- Fully responsive
- Zero dependencies
